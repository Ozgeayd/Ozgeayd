## 😎 Hi there, I'm Özge!

I am a **4th-year Computer Engineering student** at **Balıkesir University**, driven by a passion for building intelligent, scalable, and user-centric software systems.

## 🚀 Focus Areas & Interests

Rather than limiting myself to a single domain, I enjoy exploring the intersection of different technologies and solving complex engineering problems:

* 🧠 **Artificial Intelligence & LLMs:** Designing Retrieval-Augmented Generation (RAG) architectures, local LLM orchestration, computer vision pipelines (YOLO), and on-device machine learning inference (ONNX).
* 📱 **Native Mobile Development:** Crafting modern, reactive Android applications with Kotlin and Jetpack Compose, alongside low-level graphics processing using OpenGL ES.
* 📊 **Data Engineering & Analytics:** Building automated web scraping pipelines, working with vector databases, and performing high-performance analytical querying.
* ⚙️ **Embedded & Telemetry Systems:** Digital logic modeling, microcontroller workflows, and real-time telemetry simulation for motorsport engineering.
